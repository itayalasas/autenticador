¿QUÉ SE CORRIGIÓ?
=====================================================

ANTES:
- La función SIEMPRE asignaba el rol por defecto (is_default = true)
- Ignoraba el campo "role" que venía del formulario
- Resultado: Todos los usuarios tenían rol "user"

AHORA:
- La función BUSCA el rol por display_name (ej: "Cliente")
- Si no lo encuentra, busca por name (ej: "cliente")
- Si aún no lo encuentra, usa el rol por defecto
- Resultado: Los usuarios tienen el rol que seleccionaron

=====================================================
LÓGICA ACTUALIZADA:
=====================================================

1. Usuario selecciona "Cliente" en el formulario
2. Frontend envía { role: "Cliente" } en el payload
3. Backend busca en application_roles WHERE display_name = "Cliente"
4. Asigna ese rol al usuario en user_roles
5. ✅ Usuario creado con rol "cliente"

=====================================================
PROBAR DESPUÉS DE ACTUALIZAR:
=====================================================

1. Ve al formulario de registro
2. Selecciona "Cliente" en "Tipo de Usuario"
3. Completa el registro
4. Ve al dashboard → Usuarios
5. ✅ Deberías ver el usuario con rol "cliente"
