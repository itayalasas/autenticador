## 🚀 CÓMO USAR

### Paso 1: Recarga la Página
```
Ctrl + Shift + R (Windows/Linux)
Cmd + Shift + R (Mac)
```

### Paso 2: Ir a Branding
```
http://localhost:5173/branding
```

### Paso 3: Verás los Tabs
```
┌─────────────────────────────────────────────────┐
│  [📦 Básico]  [🎨 Avanzado]  [💬 Textos]       │
└─────────────────────────────────────────────────┘
```

   - **Colores extendidos**
   - **Efectos visuales**
   - **Layout**
   - **Mensajes**

### Paso 5: Ver Cambios en Tiempo Real
- Cambia cualquier control
- La vista previa se actualiza **instantáneamente**

- Todo se ve reflejado inmediatamente
